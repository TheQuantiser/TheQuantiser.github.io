# Quantiser Aurora Theme

A Hugo theme adapted and customised for [Mohammad Abrar Wadud](https://thequantiser.github.io).

## Features

- Retro look using the Fira Code typeface
- Dark/light mode toggle
- Pagefind-powered search
- KaTeX support for mathematics
- Nested menus and post pagination

## Usage

The theme is located at `themes/aurora` and is referenced from `hugo.toml` with `theme = "aurora"`.
All assets are processed with Hugo Pipes so no additional build steps are required. Styles live under `assets/css/` and are concatenated automatically. Customise layouts in `layouts/` and styles in `assets/` as needed.
